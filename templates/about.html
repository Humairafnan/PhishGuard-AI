About PhishGuard AI

An explainable artificial intelligence system for phishing email detection.

Project Overview

PhishGuard AI is a phishing email detection system developed using a hybrid ELECTRA-CNN deep learning architecture. The system combines contextual language understanding from ELECTRA with CNN-based feature extraction to identify phishing-related patterns in email content.

Unlike traditional black-box detection systems, PhishGuard AI provides Explainable AI (XAI) insights using Integrated Gradients, allowing users to understand which words contributed to the final prediction.

Core Technologies

🧠 ELECTRA-CNN Hybrid Model

ELECTRA generates contextual representations of email text, while CNN layers capture important local linguistic patterns.

🔍 Explainable AI

Integrated Gradients highlights important tokens that increase or decrease the phishing prediction score.

🌐 URL Security Analysis

Embedded URLs are analyzed using security rules including domain reputation, suspicious keywords, and URL characteristics.

System Capabilities

  • Email phishing classification using deep learning
  • Confidence-based risk assessment
  • URL-based security analysis
  • Human-readable AI explanations
  • Technical XAI visualization for transparency

Current Limitations

Although the system achieves strong phishing detection capability, some legitimate emails may contain phishing-like patterns such as verification requests, security warnings, and account-related language. These cases may require additional contextual verification.

The current URL analysis relies on rule-based security indicators rather than real-time website reputation checking.

Future Improvements

  • Integration with real-time URL reputation services.
  • Continuous learning from new phishing campaigns.
  • Improved multilingual phishing detection.
  • Deployment optimization for large-scale email systems.
